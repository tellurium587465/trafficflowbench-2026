# デジタルツイン(合成の月)— 転移を手元で測るための物差し

目的は POLICY_20261012.md §3 のとおり。テスト月の「新しいシナリオの種による渋滞地図のずれ」を手元で再現し、LB を使わずに転移を測る。

## 段階と検査(すべて学習月のデータだけを使う。検証・本番の月の観測には触れない)

| 段 | スクリプト | 中身 | 検査と結果 |
|---|---|---|---|
| 1 | ctm_replay.py | 学習月の平日を CTM で再現。入力は上流端の観測流量、接続部の出入りの比、fd_parameters | D12_I5_S:IoU 0.40、渋滞量 1606/1698、最初の渋滞の時刻はほぼ一致 |
| 2 | gen.py | 世界 A(学習月の全日の再現)と、テストの世界 8 か月(引き直しあり)をキャッシュ形式で書き出す | check_world.py の TV:A の月どうしは本物と一致、テスト vs A は 0.04〜0.45(本物 0.10〜0.40) |
| 3 | build_nn.py | 本物と同じ関数で 80 列の NN 入力を作る(列名の一致を assert) | — |
| 3 | eval_twin.py | 世界 A で学習したモデルをテストの世界で採点。提出と同じ後処理を使い、比較は (路線 × 世界) 単位のブートストラップ | 妥当性の検査(下記) |

## 妥当性の検査(物差しとして使う前の関門)

LB の事前宣言つきのプローブで確かめた向きを、合成の世界が再現するか。

- 時刻・静的を外す:+(s42)
- 時刻を残す:−(s49)
- onset の根拠:+(s45)
- 遠い予測の判定:+(s34/s40)

半分以上を再現できなければ、物差しとしては使わない。

## 生成の設定(gen.py)

- 容量:×exp(N(0, 0.015))(リンクごと)
- 自由流速度:×exp(N(0, 0.01))
- 接続部の出入り:各接続点の正味の対数比 × (1 + N(0, 0.4))
- 上流需要:×exp(N(0, 0.03))
- 事故:路線・月あたり 0.8 件、容量 ×0.5 を 30〜90 分
- 観測の雑音:速度 0.8%、流量 2.3%
- 欠け・適格・T1 の隠し・ランプ:実際の学習月から日ごとに写す

## 既知の限界

- 第 1 段で、並んだ 2 つ目のボトルネック(混雑時だけ大きくなる合流、または事故の多い場所)を再現できていない。
- 世界 A の地図と本物の地図の差は TV 0.18〜0.57。合成の世界は「本物と同じ構造の別の世界」として使い、本物の代わりにはしない。
